# תוצאות בדיקות קבלה

תאריך: 24.10.2026. כל המתכונים, החשבונות והקבצים בבדיקות הם נתונים סינתטיים נפרדים, ואינם מתכונים של הבעלים. לא בוצעה קריאת OpenAI בתשלום.

- `npm run test:unit`: עשרים בדיקות עברו, ובהן כמויות מדויקות, חלופות, המרות, ביצים, תלויות, מזווה והשוואת חילוץ. עשר מהן מגינות גם על הקוד הקודם.
- `npm run test:ui`: חמש בדיקות הממשק הקודם עברו.
- `npm run build`: בדיקות TypeScript ובניית Vite עברו.
- `npm run test:integration`: אחת־עשרה בדיקות משנה בתוך בדיקה ראשית עברו עם PostgreSQL, HTTP, תהליכי worker ו־FFmpeg אמיתיים.
- `npm run test:e2e`: ארבע בדיקות Chromium עברו באמולציית נייד עם מגע ועברית ברוחב 390 פיקסלים. נבדק גם גובה 480 המדמה שטח מצומצם בעת הקלדה.
- `npm audit --omit=dev --audit-level=high`: לא נמצאו חולשות בחבילות הריצה בזמן הבדיקה.
- חבילת Docker נבנתה והופעלה בפועל מהתקנה נקייה עם PostgreSQL 17, API ו־worker נפרדים ו־volumes מתמשכים. נבדקו יצירת בעלים במסוף, התחברות, שמירת מתכון, עיבוד thumbnail ב־worker, חסימת מדיה לא מאומתת וגיבוי מתוך הקונטיינר. תפקיד `kitchen` אינו superuser ואינו מורשה ליצור מסדים או תפקידים; סיסמת מנהל האתחול אינה מועברת ל־API.

בדיקות האינטגרציה מאפסות רק schema במסד ייעודי `kitchen_test`. תרחיש השחזור משתמש במסד נוסף ובאחסון חדש. הבדיקות מכריחות מפתח AI ריק ותקציב אפס. ספק מלאכותי בודק התמדה וזרימה בלבד.

FFmpeg המיר בפועל סרטון ובנה poster, וגם המיר הקלטת WebM במבנה streaming ל־MP3. מתאם S3 מוכן אך לא נבדק מול דלי מרוחק; האחסון המקומי נבדק. קיים fallback ל־heif-convert ב־Docker, אך לא נמסרה תמונת HEIC אמיתית לאימות כיוון וקודק.

אין הבטחת צלצול כשהמכשיר נעול. הקראת דפדפן תלויה בקול עברי זמין; גיבוי הקול בשרת דורש חיבור AI ובדיקת מכשיר. לא הוקם מאגר GitHub מרוחק ולא בוצע אירוח ציבורי. הפעלה מקומית אינה כתובת נגישה בטלפון מחוץ למחשב.
