# GitHub, Supabase, Neon ו־Render במסלולים חינמיים

נבדק בתיעוד הרשמי ובחיבורים הזמינים ב־24.10.2026. לא נרכש שירות, לא שודרג מסלול ולא שונה פרויקט קיים.

GitHub Free מאפשר מאגרי קוד פרטיים ללא הגבלה, ולכן אין צורך לשדרג כדי לשמור את קוד האפליקציה במאגר פרטי. המכסה המתועדת לחשבון אישי כוללת 2,000 דקות Actions בחודש. GitHub Pages הוא אירוח סטטי: הוא אינו מפעיל שרת Node, מסד או worker עם FFmpeg. תמונות המתכונים והמפתחות אינם מיועדים לשמירה ב־Git.

יצירת המאגר דרך ההרשאה המחוברת נכשלה בעבר עם `Resource not accessible by integration`. לאחר שהבעלים יצר את המאגר, הקוד הועלה ל־[my-kitchen](https://github.com/h0527040060-debug/my-kitchen), בענף main. הבעלים בחר במפורש להשאיר את קוד האפליקציה ציבורי; נתוני המתכונים, המדיה והמפתחות נשארים פרטיים ומחוץ ל־Git. בדיקות GitHub Actions עברו בענן.

מקור: [GitHub plans](https://docs.github.com/en/get-started/learning-about-github/githubs-plans).

המכסות המתועדות ל־Supabase Free כוללות:

| רכיב | מכסה |
|---|---|
| פרויקטים חינמיים פעילים | שניים בסך הכול בארגונים שבהם החשבון Owner או Administrator |
| מסד נתונים | 500MB לפרויקט |
| אחסון קבצים | 1GB |
| תעבורה יוצאת | 5GB |
| חוסר פעילות | פרויקט עשוי להיעצר אחרי פעילות נמוכה לאורך שבעה ימים |

אלה מכסות התוכנית, ולא מדידה של המקום הפנוי אצלך. בבדיקה לקריאה בלבד נמצאו `CRMove` ו־`crmove-backup` פעילים בשני החיבורים, וכן שני פרויקטים לא פעילים בחיבור הראשי. אין להניח שניתן לפתוח פרויקט חינמי שלישי: מערכת Supabase קובעת את המכסה לפי בעלות החשבון והארגונים. לא עצרנו פרויקט קיים כדי לפנות מקום.

מסד אישי עשוי להתאים למכסת המסד, אך המקור, התצוגה והתמונה הממוזערת נשמרים בנפרד. לדוגמה, 1,000 תמונות מקור בגודל 3MB הן כ־3GB לפני נגזרות או סרטונים. אי אפשר להבטיח שאלפי תמונות ייכנסו ל־1GB החינמי. יש למדוד את האוסף לפני העלאה רחבה.

אפשר לחבר את השרת ל־PostgreSQL של Supabase באמצעות `DATABASE_URL` של שרת, TLS ו־schema פרטי. הדפדפן אינו צריך מפתח service-role. לא הוחלו מיגרציות על הפרויקטים הקיימים. ה־worker ועיבוד FFmpeg עדיין זקוקים למקום הרצה משלהם.

מקורות: [מכסות וחיוב](https://supabase.com/docs/guides/platform/billing-on-supabase), [עצירה בחוסר פעילות](https://supabase.com/docs/guides/platform/free-project-pausing).

ניסיון ליצור פרויקט Supabase ייעודי נדחה בפועל בשל מגבלת שני פרויקטים פעילים. לא שינינו או עצרנו פרויקט קיים. המכסה אינה נפרדת לכל ארגון של אותו חשבון. אין כאן אישור לכך שפתיחת חשבונות באימיילים נוספים כדי לצבור מכסות מותרת בתנאי הספק; לשאלה זו נדרש אישור Supabase. בחיבור ChatGPT הנוכחי קיימים שני קישורי Supabase נבחרים בנפרד, אך קישור נוסף אינו מוכיח שזהות הבעלים או מכסת הפרויקטים שונות.

החלופה שנבחרה היא **Neon Free**, עם PostgreSQL ואחסון קבצים תואם S3. פרויקט `my-kitchen` נוצר תחת ארגון Free, באזור Frankfurt, עם ענף `main`, ענף בדיקה נפרד ודלי פרטי. לא הוחלף מסלול בתשלום.

| מכסת Neon Free המתועדת | ערך |
|---|---|
| פרויקטים | עד 100 |
| מסד | 1GB לפרויקט |
| Object Storage | 5GB לפרויקט |
| חישוב מסד חודשי | 100 CU-hours לפרויקט |
| כרטיס אשראי לפתיחת Free | אינו נדרש לפי המחירון |

מקורות שנבדקו ב־24.10.2026: [Neon pricing](https://neon.com/pricing), [Object Storage limits](https://neon.com/docs/storage/overview). אלה מכסות תוכנית, לא נפח פנוי שנמדד; 5GB אינם הבטחה לאוסף בלתי מוגבל. אין מעבר אוטומטי למסלול בתשלום מתוך קוד האפליקציה.

האפליקציה מתארחת ב־Render Free; מסד ותור ומדיה נשמרים ב־Neon. יש שינה ומכסות משותפות, והעיבוד עשוי להמתין להתעוררות. [הנחיות ומגבלות, כולל חריגות חיוב אפשריות בחשבון עם אמצעי תשלום](CLOUD-FREE.md). החבילה המקומית נשארת חלופה לפיתוח. OpenAI API הוא חיוב נפרד ואינו כלול במנוי GitHub, Neon, Supabase או ChatGPT; הוא כבוי בפריסה הנוכחית.
