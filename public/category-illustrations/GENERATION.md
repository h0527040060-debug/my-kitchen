# Category illustration library

Generic food illustrations created with the ChatGPT image-generation tool on 2026-10-25 for this application. No user recipe images or private content were used. The tool did not report a model identifier.

`main.webp` is a 4×4 atlas: cooking, baking, desserts, beef; chicken, fish, salads, soups; cake, cookies, cheesecake, bread; rice, pasta, liver pate, sauces.
`extra.webp` is a 2×2 atlas: hummus, muffins; savory pastries, fruit tart.

Prompt version: category-atlas-he-v1. Assets are exported as WebP, then the worker prepares private category-sized images. These are illustrative category pictures, never proof of a user cooking the pictured food. Runtime category pictures use these bundled assets without any model API request.
